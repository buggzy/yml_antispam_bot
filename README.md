## Telegram антиспам бот на Python

**Функции**
- Читает сообщения в группе и проверяет через OpenAI — относятся ли они к запретным темам.
- Удаляет нарушение и публикует исчезающее через 60 секунд уведомление вида: `сообщение от <user> удалено по причине <reason>`.
- Пары «промт — причина удаления» хранятся в `settings.json`.

**Требования**
- Python 3.10+
- Бот должен быть администратором группы с правами удаления сообщений.

**Установка**
1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Создайте файл `.env` в корне и задайте переменные:
```bash
TELEGRAM_BOT_TOKEN=123456:ABC...
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
SYSTEM_PROMPT=Ты модератор чата. Определи, относится ли сообщение к одной из запретных тем из списка правил. Если да, верни JSON {"is_forbidden": true, "reason": "<краткая причина из словаря>"}, иначе верни JSON {"is_forbidden": false}.
```
3. Отредактируйте `settings.json` — список правил.

**Запуск**
```bash
python main.py
```

**Примечания**
- Убедитесь, что у бота отключён режим приватности через BotFather (`/setprivacy -> Disable`), чтобы он видел сообщения в группе.
- Уведомление удаляется через 60 секунд автоматически.
