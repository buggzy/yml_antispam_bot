## Telegram антиспам‑бот (aiogram v3)

**Возможности**
- Проверяет новые и отредактированные сообщения (в т.ч. подписи к фото) на соответствие запретным темам (OpenAI).
- При нарушении удаляет сообщение и публикует уведомление, которое удаляется через 60 секунд.
- Реагирование на команды:
  - В личке: `/start`.
  - В группах: команда из `settings.json` → поле `group_command` (по умолчанию `yml_antispam`).
- Проверяет права: бот должен быть администратором с правом удаления сообщений (`can_delete_messages`). Если права потеряны, бот сообщает об этом в чате один раз.

**Требования**
- Python 3.8+ (на Linux протестировано с 3.8/3.11)
- Бот — администратор группы с правом удаления сообщений.

**Установка**
1) Установите зависимости:
```bash
pip install -r requirements.txt
```
2) Создайте `.env` в корне проекта:
```bash
TELEGRAM_BOT_TOKEN=123456:ABC...
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
# опционально
DEBUG=false
```
3) Отредактируйте `settings.json`:
```json
{
  "forbidden_topics": [
    { "prompt": "осталось несколько билетов, покупайте быстрее", "reason": "подозрительная продажа билетов" }
  ],
  "group_command": "yml_antispam"
}
```

**Запуск локально**
```bash
python main.py
```

**Команды**
- Личка: `/start` — краткое сообщение о статусе.
- Группа: `/<group_command>` — отвечает «Бот антиспама активен.» при наличии прав; иначе просит выдать права на удаление.

**Примечания**
- Рекомендуется отключить режим приватности через BotFather: `/setprivacy -> Disable`, чтобы бот видел сообщения в группе.
- Уведомление об удалении исчезает через 60 секунд.
